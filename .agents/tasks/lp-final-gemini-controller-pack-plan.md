# Implementation Plan

## Scope, source policy, and decisions

This is a documentation-only plan. The implementation agent must create only:

- `docs/prompts/LP-FINAL-GEMINI-CONTROLLER-PACK.md`
- `docs/handouts/LP Final - Gemini controller writing pack.docx`
- `docs/handouts/LP Final - Gemini controller writing pack.pdf`

It must not modify game code, Unity scenes, prefabs, assets, `ProjectSettings`, repository tooling, branches, refs, commits, or history. It must not fetch, check out, switch, commit, or push. All output remains uncommitted.

**Source-of-truth decision.** Use local `origin/main` at `06fe0ff8d53634509cf608e85209c4f223d87123` as the repository source of truth. Read tracked content with `git show`, `git grep`, `git ls-tree`, and ancestry/diff commands against that ref. The current checkout is stale and must not override evidence from `origin/main`.

**Missing/private-document decision.** The writing pack must say near the top that this investigation did not read the private Google Doc or use any “LP Final Submission” content as evidence. Gemini must inspect the open Google Doc before writing. The planning baseline unexpectedly lists an untracked `docs/LP Final Submission.pdf`; it was deliberately not opened, parsed, or relied on. Do not imply otherwise, and do not copy from it.

**Status decision for the controller work.** Keep three states separate: (1) historical work that is an ancestor of `origin/main`, (2) the branch-only `CrazyTechniques.cs` implementation in `6061f54`, and (3) the later, different `TaxiTrickRecognizer`/`VehicleController.Taxi` implementation now present on `origin/main`. This avoids calling the branch-only component player-available while still describing the independently integrated current controller accurately.

**Measurement decision.** The main measurement table will use the newer tracked 26 October CSV for the current controller. The older `VehicleLab_Measurements/vehicle_measurements.csv` figures will appear only in a clearly labelled historical comparison. Arithmetic from the turning-geometry report belongs in a separate “Derived estimates, not measurements” table.

**Rendering decision.** Use `docs/tooling/md_to_docx.py` directly because `docs/tooling/build_handouts.ps1` has a fixed document map and does not name this pack. Do not edit the script just to add one output. Use Microsoft Word through the converter’s `--pdf` option, with manual Word Save As PDF only as a fallback.

Content was rephrased for compliance with licensing restrictions.
