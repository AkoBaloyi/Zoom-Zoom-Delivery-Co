QA-008 reproduction: launch → Controls. Expected: the screen describes implemented player actions, with relevant input-device bindings. Actual: only acceleration, steering, brake/reverse and handbrake are listed. Evidence: `01-controls.jpg` and `VehicleControls.inputactions`. Likely cause: manually authored UI text has not kept up with the input map. Fix: update the screen, preferably reading binding labels from the input asset, then test discoverability with new players.

**Build/source discrepancy:** the running executable logs a 45-second time limit, while the checked source `OrderTuning_Balanced.asset` says 50. This is a confirmed discrepancy; the cause (build age, asset import/defaults, or another configuration difference) is unverified. Do not apply the earlier 50-second route calculation to this build. Reconcile the build configuration and record build provenance before balance comparisons.
